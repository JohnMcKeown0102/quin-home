Quin privacy policy

Last updated: 25 November 2026

What Quin accesses

With the account owner's permission, Quin reads calendar events from Google Calendar, using the read-only scope calendar.events.readonly. It cannot create, edit or delete events.

Google sends Quin the full details of each event. Quin uses the title, the start and end time, the description (only to choose which family member's label to show) and whether the event was cancelled or declined. It ignores the rest.

If the household connects its Nest thermostat, Quin also uses the scope sdm.service to read the room temperature, humidity, target temperature, mode, Eco setting, and whether the thermostat is heating and online. When someone in the household presses a heating button, Quin sends that change to the thermostat through Google.

How the data is used

The titles, times and labels of events for the next seven days are shown on the household's own paired tablet and phone. Descriptions are not shown. A recent copy is kept in memory so the display keeps working if Google cannot be reached. Events are not stored in a database, not written to logs, and not used for anything else.

Thermostat readings are shown on the same paired screens. Only the latest reading is kept, in memory. Readings are not stored in a database and not written to logs.

Where the data goes

Quin runs on a Raspberry Pi on the home network. Apart from the thermostat changes it sends to Google, data from Google is not sent to any other service, not sold, not shared and not used for advertising or to train AI models. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time from the Google Account page Third-party apps and services. Quin then stops showing events, and can no longer read or change the thermostat.
